# Thunkable

> Thunkable is a no-code, AI-powered platform for building native iOS and Android mobile apps with a visual drag-and-drop designer, a block-based logic editor, and conversational AI prompts. Apps built on Thunkable connect to external services through the in-app Web API blocks (HTTP requests against any REST endpoint), realtime databases, cloud storage, maps, media, and payment providers. Thunkable does NOT publish a first-party developer REST API, OpenAPI specification, or SDK for programmatically managing Thunkable projects — its "API" surface is the Web API component used to consume third-party APIs from inside apps.
